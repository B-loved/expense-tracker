# 💰 Expense Tracker (Quản lý chi tiêu)

Đây là một project Python chạy trên Ubuntu giúp quản lý và theo dõi các khoản chi tiêu cá nhân.

## 🚀 Các tính năng chính
- Thêm khoản chi tiêu mới.
- Lưu trữ dữ liệu vào file CSV (`data/expenses.csv`).

## 🛠️ Hướng dẫn cài đặt và sử dụng

**1. Clone project về máy:**
\`\`\`bash
git clone https://github.com/B-loved/expense-tracker.git
cd expense-tracker
\`\`\`

**2. Cài đặt thư viện:**
\`\`\`bash
pip install -r requirements.txt
\`\`\`

**3. Chạy chương trình:**
\`\`\`bash
python main.py
\`\`\`
